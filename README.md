## How I work

I start with the physical or mathematical question, identify the assumptions, and build a calculation I can inspect. I use synthetic examples to explore behavior and check numerical results against the definitions they are supposed to implement.

I care about the details that change an answer: units, sampling, coordinate conventions, complex conjugation, normalization, and sensitivity to perturbations. I keep exploratory results separate from validated claims.

## Technical interests

- **Physics and mathematics:** wave propagation, acoustics, linear algebra, complex eigenproblems and geometric descriptions of polarization.
- **Scientific computing:** Python, NumPy, SciPy, Matplotlib, Jupyter and C++.
- **Software practice:** reproducible examples, explicit dependencies, Git versioning and documented limitations.
