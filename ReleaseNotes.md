# Release notes

Newest first. The first section's bullet points are shown in the app's update banner,
so write them for the person using the app.

## 1.2
- Fixed: Manuscript Studio sign-in (the app read its settings from the wrong address), so your papers now open in the Manuscript tab
- Google Drive setup now shows what happened, closes itself when connected, and says exactly what went wrong if not
- Adding a paper keeps its figures: pictures in the file are uploaded to the paper's private files, as the web editor does
- If sign-in stops, the message says at which step, and Settings › Copy a problem report includes it

## 1.1
- New Manuscript tab: your Manuscript Studio papers with everything from the web app (writer, equations, highlights, comments with pictures and replies, history, references, files, PDF ink, templates, tabs and split views, Word/PDF export)
- Sign in once with Google; the web app opens already signed in
- Ask Claude (Opus 5.5, High) or ChatGPT (Astra, High) about the paper, by typing or with the keyboard mic
- They can propose edits, equation fixes, comments, highlights, replies, resolving comments and checklist ticks; you see every change first and tap Apply
- Applied changes become a new revision in Manuscript Studio, with full version history
- Add your Claude and ChatGPT keys in Settings (kept safely through updates)
- Add a paper (＋ in the Manuscript tab) from a LaTeX, Markdown, HTML, text or Word file: it becomes its own paper in Manuscript Studio, with a checklist built from its sections

## 1.0
- Every paper is a tree: sections, subsections and each equation, figure, table and check, with Claude-style marks (dashed circle, spinning arc, green tick)
- Tap a mark to start or finish an item; parents fill in by themselves and show a progress bar
- Green–Christoffel is ready: 39 equations, 7 figures, 2 tables, the open review flags, text checks for every section and a Submission stage
- XP, levels, a daily goal ring and a streak; confetti when a subsection, section or the whole paper is done
- "Next up" shows the one thing to do now, with Start and Done buttons
- Syncs with Google Drive › Paper Quest after every change, so your iPhone, iPad and Claude see the same progress
- Open the manuscript (Manuscript Studio) from any paper or item, and copy the LaTeX reference of an equation, figure or table
